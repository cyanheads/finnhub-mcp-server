# 0.2.0 — 2026-10-30

## Added

- **Workflow guidance:** Publish the finnhub-guide skill and serve it as an MCP resource. Plugin installs, npm, Docker, and the desktop bundle carry the guide.
- **Plugin metadata:** Add the Agent Plugins root manifests alongside the Claude Code and Codex overlays.

## Changed

- **Ticker inputs** trim surrounding whitespace and uppercase symbols across quotes, company data, earnings, company news, and recommendations, preserving class-share punctuation ([#9](https://github.com/cyanheads/finnhub-mcp-server/issues/9)).
- **Coverage recovery** conditionally explains missing ETF, fund, or trust data and suggests quotes while retaining ticker verification ([#7](https://github.com/cyanheads/finnhub-mcp-server/issues/7)).
- **Recommendation limits** describe available upstream rows without promising a fixed history depth ([#6](https://github.com/cyanheads/finnhub-mcp-server/issues/6)).
- **Development tooling** syncs framework skills and verification scripts; install examples, issue reporting, and the one-day dependency age guard follow the updated templates.

## Fixed

- **Desktop bundles** retain SDK skills runtime modules while stripping development files, dependency agent documentation, node-gyp intermediates, and build-only package files.
