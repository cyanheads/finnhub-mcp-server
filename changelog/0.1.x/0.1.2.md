# 0.1.2 — 2026-08-21

## Changed

- **MCP SDK v2** — framework `@cyanheads/mcp-ts-core` ^0.10.6 → ^0.12.3. Every endpoint now also serves protocol revision 2026-07-28 alongside the 2025 era; existing 2025-era clients keep working.
- **Strict tool inputs** — an argument key a tool's schema does not declare is rejected by name instead of stripped.
- **Error envelope on the wire** — the advertised output schema declares `error`, so clients that validate `structuredContent` without checking `isError` stop rejecting error results with `-32602`.
- **`missing_symbol` reclassified** — `finnhub_get_earnings` (history mode) and `finnhub_get_news` (company mode) return `ValidationError` instead of `InvalidParams` when the required symbol is absent.
- **Bun 1.4.0** — Dockerfile pins on both stages plus `packageManager`; the build stage runs natively per architecture so multi-arch pushes do not emulate Bun; the production image omits optional peer tiers.
- **Supply-chain guard** — `bunfig.toml` holds freshly published versions for 3 days and runs the Socket security scanner on every install; framework releases are excluded and adopt same-day.
- **TypeScript ^7.0.2** — and the tsconfig split typechecks `tests/` alongside `src/`.

## Fixed

- **Fetch timeouts classify as `Timeout`** again rather than surfacing as `ServiceUnavailable`.
- **`withRetry` honors upstream `Retry-After`** headers instead of blind exponential backoff.
- **A stalled response body aborts** — the request deadline now bounds the whole exchange, not just the response headers.
- **`MCP_AUTH_MODE=none` no longer advertises OAuth** protected-resource metadata over HTTP.
- **Stateful HTTP replays dropped SSE streams** — a client reconnecting with `Last-Event-ID` receives the frames it missed.
