# 0.1.5 — 2026-09-20

## Changed

- **`MCP_SESSION_MODE`** — `src/index.ts` declares `sessionMode: 'stateless'` via `createApp()`; an unset variable now resolves there instead of the framework's `auto` default, which previously resolved to `stateful`. An explicit environment value still wins. ([#8](https://github.com/cyanheads/finnhub-mcp-server/issues/8))
- **Repo hygiene** — development skills moved from `skills/` to `framework-skills/` (Claude Code and Codex auto-load a plugin's root `skills/`); adds `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, and a CodeQL workflow.

## Fixed

- **Plugin installs deliver `FINNHUB_API_KEY`** — `.claude-plugin/plugin.json` gains a `userConfig` block and `.codex-plugin/mcp.json` gains `env_vars`, replacing a hardcoded placeholder that never reached the server.
