# 0.1.6 — 2026-10-07

## Changed

- **Framework error handling** — clearer field-path argument hints and safe input repairs (0.13.9), automatic declared recovery hints and tool error request IDs (0.13.10), generated correlation IDs and origin-only URL redaction (0.13.12), and internal root causes kept off wire errors (0.13.13).
- **Framework logging** — client log messages honor the configured level and redact sensitive fields (0.13.11); every sink uses a bounded redacting walk (0.13.13). Document opt-in OTLP log export and failed-call payload logging introduced in 0.13.8.
- **Docker builds** — Bun 1.4.2 builds and cross-installs production dependencies on the native build platform, installs OTel peers at framework ranges through the supply-chain guards, and prunes musl-only packages before copying into the runtime image.
- **Bundles and metadata** — exclude built `.mcpb` files from npm packages and local caches, logs, and design notes from bundles; broaden env/token exclusions. MCP Registry entries launch through `npx`, with HTTP transport fixed through `MCP_TRANSPORT_TYPE`.
- **Development tooling and docs** — sync framework skills and verification scripts, including definition-load failures, packaging and tag checks; refresh per-language CodeQL categories, configuration examples, tool summaries, and directory documentation.
