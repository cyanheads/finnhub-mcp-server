# 0.1.4 — 2026-08-30

## Changed

- **`finnhub_get_quote`** — exposes nullable Finnhub `session` and `holiday` status fields, including rendered freshness and holiday detail, while retaining the existing `priceIsLive` contract. ([#2](https://github.com/cyanheads/finnhub-mcp-server/issues/2))
- **`finnhub_get_earnings`** — calendar mode now passes an optional `symbol` filter to Finnhub and keeps market-wide behavior when it is omitted. ([#4](https://github.com/cyanheads/finnhub-mcp-server/issues/4))
- **`finnhub_get_news.limit`** — accepts up to 100 articles from one fetched response; the default and truncation enrichment remain unchanged. ([#5](https://github.com/cyanheads/finnhub-mcp-server/issues/5))
