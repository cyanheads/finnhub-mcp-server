# 0.1.3 — 2026-08-30

## Changed

- **`isLikelyUS`** — recognizes `.A` and `.B` US class-share symbols and ranks likely-US Common Stock results first; the documented flag remains a symbol-format heuristic, not an availability guarantee. (#1)
- **`MCP_SESSION_MODE`** — the environment example, HTTP launch example, and configuration reference explicitly select `stateless`; an unset value still follows the framework's `auto` behavior. (#8)

## Fixed

- **`finnhub_search_symbols.query`** — rejects inputs longer than Finnhub's 20-character search limit before making an upstream request. (#3)

## Dependencies

- `@biomejs/biome` `2.5.9` → `2.5.11`
- `@types/node` `26.2.0` → `26.4.0`
